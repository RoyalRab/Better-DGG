Settings

Using the Chrome app on Android? Install from Chrome (⋮ → Add to home screen), and let Chrome run in the background so sound keeps playing with the screen locked: on Samsung, Settings → Battery → Background usage limits, and make sure Chrome isn't a sleeping app.

To install on iPhone or iPad: tap Share, then Add to Home Screen.

Better DGG Pro is an unofficial fan-made app and isn't affiliated with destiny.gg.
